# Pre-built Android APK

This directory contains the pre-compiled debug APK of the **GNSS Signal & C/N₀ Viewer** application.

- **File**: `app-debug.apk`
- **Minimum Android Version**: Android 8.0 (API 26+)
- **Target Android Version**: Android 15 (API 35)

---

## How to Install on Your Android Device

1. Download [`app-debug.apk`](./app-debug.apk) directly onto your Android phone or tablet.
2. Tap the downloaded file in your browser or File Manager.
3. If prompted with *"For your security, your phone is not allowed to install unknown apps from this source"*, tap **Settings** and toggle **Allow from this source**.
4. Tap **Install**, then **Open**.
5. Grant the **Precise Location** permission when asked to allow GNSS hardware access.
